    Examples Index¶

    All first-party examples live in the core rt repository under examples/. Each page below is a full source walkthrough (tasks, shared state, control flow, APIs, pass/fail, build). Host binaries: ./build/signal/examples/... after scons.

    Functional examples¶

    Page Blurb
    empty Smallest smoke test: one task drops privilege and rt_exits.
    simple Two equal-priority arg-tasks yield 100×; arg==1 exits.
    sem Poster/waiter counting semaphore with intentional timed-wait failure.
    mutex Three lock styles (guard / trylock / timedlock) on one counter + last-exit sem.
    recursive Nested foo→bar locking on RT_MUTEX_RECURSIVE.
    donate Priority inversion + donation; strict sequence() order 0…10.
    fair Four equal-priority tasks assert mutex handoff fairness.
    cond Signaler + two incrementers on RT_COND / predicate flag.
    event Event bits with ALL vs ANY+NOCLEAR waits and a final timeout.
    notify Notify OR/clear-wait loop mirroring the sem timing pattern.
    queue Dual pushers + peek/pop ordering stress until duration exit.
    rwlock Readers assert x==y while a writer bumps both under write lock.
    once Contended rt_once_call with deliberate once.done reset.
    pool Pool get → queue → put pipeline with back-pressure.
    timer Periodic software timer start/stop/change_period count checks.
    sleep rt_task_sleep_periodic wake skew ≤1 tick for two periods.
    tls Per-task foo/bar isolation via TLS or split statics.
    float FP accumulate across yields with RT_STACK_FP_MIN.

    Cycle micro-benchmarks¶

    Instrumentation harnesses: stamp rt_cycle(), exercise a primitive N=100 times, store deltas, rt_trap() for inspection (not assert-based pass/fail).

    Page Measures
    cycle-yield Equal-priority yield handoff latency.
    cycle-sleep 1-tick sleep wake timing.
    cycle-sem Sem post→wait latency.
    cycle-mutex Contended mutex unlock→lock latency.
    cycle-event Event set→wait latency.
    cycle-notify Notify post→wait latency.
    cycle-queue Queue push→pop latency.

    Water synchronization lab¶

    Shared harness water/water.c + water.h (hydrogen / oxygen / make_water). Two H loops (prio 2), one O loop (prio 1), timeout supervisor (1000 ticks) checks bond counts. Variants only change the rendezvous implementation:

    Page Strategy
    water-sem Atomic H pairing + h2ready / hdone semaphores.
    water-cond Mutex + hready / hdone condition variables.
    water-barrier Capacity sems (2 H, 1 O) + 3-party barrier around make_water.
    water-harness Shared loops, counters, and success criteria.

    See also Building and Examples and Benchmarks.
